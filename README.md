# شاشة الاستدعاء (HULUL SYSTEMS)

تطبيق أندرويد مستقل يعرض الرقم الحالي وآخر 3 أرقام وعدد المنتظرين من جهاز "تذاكر العيادة" على نفس شبكة الواي فاي.
- يبحث تلقائياً عن الجهاز الرئيسي ويتصل به (ويعيد البحث لو انقطع الاتصال).
- يعمل على التابلت والأندرويد تي في وبوكسات التلفزيون (ريموت: OK أو قائمة لضبط الاتصال).
